# Ocean Wave Footer

A responsive ocean-themed footer component created with HTML5, CSS3 and Vanilla JavaScript.

## Features

- Three layered inline SVG waves with different animation speeds.
- 15 floating background bubbles with randomized size, position and timing.
- Ocean blue/teal gradient design.
- Logo and short about section.
- Three useful link columns.
- Newsletter email validation with loading and success feedback.
- Social media icons with bubble shine and hover movement.
- Automatic copyright year.
- Responsive layout: 4 columns on desktop, 2 on tablet and 1 on mobile.
- Reduced-motion accessibility support.
- Google Fonts (Quicksand) and Font Awesome 6 CDN.

## Project files

- `index.html` — page structure and footer content.
- `style.css` — colors, layout, animations, hover effects and responsive styles.
- `script.js` — floating bubbles, newsletter interaction and current year.
- `README.md` — project information and run instructions.

## How to run

1. Extract the ZIP file.
2. Open the `Ocean-Wave-Footer` folder in Visual Studio Code.
3. Open `index.html` in a browser, or use the VS Code Live Server extension.
4. An internet connection is required for Google Fonts and Font Awesome CDN icons.

## Important note about the newsletter

The newsletter form is a front-end demonstration. It validates the email address and displays a success message, but it does not store or send email addresses to a mailing-list service. A backend or newsletter provider is required for real subscriptions.

## Customization

- Replace the sample social media URLs in `index.html` with the intended profile links.
- Replace placeholder footer links (`#home`, `#about`, etc.) with real website destinations.
- Update the author line if your submission instructions require your own name.
